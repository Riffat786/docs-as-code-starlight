This site is a demonstration. It publishes a selection of pages from the Start Docs-as-Code with Me course, using [Starlight](https://starlight.astro.build/) instead of Docusaurus.

The Markdown source is the same idea in both places: plain text in Git, reviewed through pull requests, and built into a website. Only the publishing layer changes.

## What is included

- **Welcome:** what Docs-as-Code is, and why teams adopt it
- **Markdown:** basics, frontmatter, and Mermaid diagrams
- **Docs-as-Code Workflow:** the documentation review process
- **Static Site Generators:** a comparison of publishing tools
- **Portfolio:** one case study, as a long-form example

The full course, including the Learning Hub modules, is published with Docusaurus.
